# Каталог источников

Исходники хранятся в `materials/`, чтобы репозиторий оставался самодостаточным.
Рабочие документы в `docs/` ссылаются на них по идентификаторам ниже.

| ID | Статус | Источник | Локатор |
| --- | --- | --- | --- |
| `S1` | согласованная версия, изучена полностью | Паспорт проекта | `materials/project/Согласованная_версия_паспорта_проекта.docx`; Telegram `233756`, дубликат `229648` |
| `S2` | драфт от 23 июля, изучен полностью | Онбординг и сцена Express | `materials/project/Драфт_первой_сцены_на_просчет_2307.docx`; Telegram `233760` |
| `S3` | автоматическая транскрипция, основной источник решений | Встреча с Эдиком Назаретяном 30 июля | `materials/meeting/2026-07-30-zoom-transcript.txt`; аудио рядом |
| `S4` | четыре гайда, все 153 страницы изучены | Основной стиль, иллюстрации, визуальный контент, видео | `materials/brand/` |
| `S5` | голосовая постановка задачи | Инициализация репозитория и порядок работы | `materials/meeting/repository-setup-request.ogg` |
| `S6` | переписка изучена полностью | Контекст общения с Эдиком Назаретяном | `materials/telegram/chat-context.md`; Telegram `1661449767`, `@ednazaret` |

## Правило использования

- `S3` — основной источник актуальных договорённостей. Это запись сегодняшнего
  Zoom-созвона, ссылка на который находится в `S6`.
- `S6` подтверждает связь транскрипции с Эдиком, фиксирует пост-встречный список
  задач и помогает восстановить историю изменений до созвона.
- `S1` задаёт исходные цели и продуктовый контекст, но встреча `S3` имеет
  приоритет там, где требования были уточнены.
- `S2` описывает первую сцену, но не считается утверждённым сценарием.
- `S4` обязателен для визуальных решений, но наличие лицензированных исходников
  и актуальность версии гайдов нужно подтвердить.
- `S5` не содержит продуктовых требований: он фиксирует только ожидаемую
  последовательность работы над проектом.

Подробные выводы из `S1` и `S2` находятся в
[разборе DOCX](docx-analysis.md).

Референсы из паспорта и текущая площадка разобраны в
[анализе референсов](reference-analysis.md).
