## Правило использования

- `S1` имеет приоритет для целей и общего состава проекта.
- `S2` описывает первую сцену, но не считается утверждённым сценарием.
- `S3` используется для договорённостей, которых нет в паспорте; неточные места
  следует подтверждать у участников встречи.
- `S4` обязателен для визуальных решений, но наличие лицензированных исходников
  и актуальность версии гайдов нужно подтвердить.
- `S5` не содержит продуктовых требований: он фиксирует только ожидаемую
  последовательность работы над проектом.
