PDF собран Typst и сжат для просмотра. Сохранены все 78 исходных изображений текущих 37 страниц. Старые контактные листы и промежуточные экспорты удалены при очистке; актуальный артефакт — current-review.pdf.

Использованы сохранённые actual4344 снимки и runtime receipts владельцев; новый browser capture здесь не запускался. Небольшие сгруппированные снимки подтверждают состав изменений, не служат сравнением резкости100%. Проверка PDF не заменяет художественную приёмку Михаилом. Обычная интерполяция не восстанавливает реальные детали; Flowers содержит раскрытые сохранённые области исходников.
