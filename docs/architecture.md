# Техническое решение

## Стек

- React;
- TypeScript в строгом режиме;
- Vite;
- Bun;
- CSS Modules и CSS-переменные;
- `useReducer` + Context для состояния игры;
- Motion только там, где недостаточно CSS;
- Vitest и Playwright для основных проверок;
- Biome и go-task для команд проекта.

## Сборка

После `vite build` получается каталог `dist/` с HTML, CSS, JavaScript и локальными
ресурсами. Backend и Node.js-сервер после сборки не требуются.

В Vite используется `base: './'`, чтобы архив можно было разместить не только в
корне сайта. Все необходимые ресурсы входят в сборку; внешний CDN не нужен.

Команда `go-task release` проверяет проект, проходит E2E-матрицу, собирает архив
`release/energy-plus-quest-static.zip` и тестирует его из вложенного URL вида
`/specialprojects/energy-plus-quest/`. В архиве `index.html` лежит на верхнем
уровне — дополнительную папку `dist/` загружать на площадку не нужно.

Для кеширования рекомендуется:

- `index.html` — `Cache-Control: no-cache` или короткий TTL;
- файлы из `assets/` с хешем в имени — `Cache-Control: public, max-age=31536000,
  immutable`;
- шрифты и брендовые изображения — длительный кеш с перевалидацией.

## Организация игры

Содержание сцен хранится отдельно от интерфейса. Каждая сцена описывает варианты
решения, последствия и изменение трёх показателей. Один reducer управляет
переходами между онбордингом, сценами и эпилогом.

Точный способ размещения определит команда «Энергии+». Для начала разработки
достаточно подтверждения, что площадка принимает статический HTML/CSS/JS-архив.

## Проверки

- `bun run check` — форматирование и статический анализ Biome;
- `bun run test` — unit-тесты reducer и начисления очков;
- `bun run test:e2e` — полный проход первой сцены в desktop и mobile Chromium;
- E2E также проверяет эффективные viewport для Windows zoom `125%` и `140%`,
  планшет и отсутствие горизонтального переполнения;
- `bun run build` — строгая типизация и production-сборка;
- `go-task verify` — check, unit-тесты и сборка одной командой.
- `go-task release` — все проверки, production-сборка и автономный ZIP-архив.
