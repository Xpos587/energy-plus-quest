# Техническое решение

## Стек

- React;
- TypeScript в строгом режиме;
- Vite;
- Bun;
- CSS Modules и CSS-переменные;
- `useReducer` + Context для состояния игры;
- Motion только там, где недостаточно CSS;
- Vitest и Playwright для основных проверок;
- Biome и go-task для команд проекта.

## Сборка

После `vite build` получается каталог `dist/` с HTML, CSS, JavaScript и локальными
ресурсами. Backend и Node.js-сервер после сборки не требуются.

В Vite используется `base: './'`, чтобы архив можно было разместить не только в
корне сайта. Все необходимые ресурсы входят в сборку; внешний CDN не нужен.

## Организация игры

Содержание сцен хранится отдельно от интерфейса. Каждая сцена описывает варианты
решения, последствия и изменение трёх показателей. Один reducer управляет
переходами между онбордингом, сценами и эпилогом.

Точный способ размещения определит команда «Энергии+». Для начала разработки
достаточно подтверждения, что площадка принимает статический HTML/CSS/JS-архив.
