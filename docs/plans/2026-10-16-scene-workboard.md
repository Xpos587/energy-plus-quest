# Список правок игры

Полные формулировки Тео из [исходного отзыва](../teo-feedback.md), без сокращения и редактуры. Порядок замечаний и всех 33 изображений сохранён внутри соответствующих экранов и ячеек «Общее / Мобайл / Десктоп». Чекбоксы обозначают замечания для рассмотрения, а не уже согласованные решения.

**Копирайтинг полностью вне нашей работы: это работа сценаристов.** Не переписываем, не сокращаем и не исправляем текст игры, включая кнопки, заголовки, пояснения, результаты и пунктуацию. Текстовые замечания ниже сохранены дословно только как часть отзыва Тео и материал для сценаристов; они не являются заданиями нашим агентам, в том числе после встречи с Эдиком. В смешанных пунктах работаем только с UX, компоновкой и визуалом, сохраняя все формулировки. Описание визуализации не переносим в надписи игры. Уточнения со [встречи с Гришей](../../materials/meeting/2026-10-16-grisha/summary.md) явно подписаны и не являются цитатами Тео. Изображения показывают версию из отзыва, а не подтверждают состояние текущей сборки.

Технические границы для параллельных сессий — в [заметках для агентов](2026-10-16-scene-agent-notes.md). Прежние ID укрупнённых задач сохранены там; здесь каждое исходное замечание приведено отдельно, с координатой источника в HTML-комментарии.
