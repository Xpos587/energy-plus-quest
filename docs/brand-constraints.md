# Бренд-правила «Энергии+»

Источник — четыре гайда из `materials/brand/`.

## Цвета

| Цвет | Значение |
| --- | --- |
| Оранжевый | `#FF5500` |
| Кобальтовый | `#003CA6` |
| Тёмно-синий | `#041327` |
| Белый | `#FFFFFF` |

## Типографика

- Фирменный шрифт — Normalidad Compact.
- Заголовки первого уровня используются прописными буквами.
- Минимальный размер основного текста по гайду: mobile — `16 pt`, tablet —
  `18 pt`, desktop — `22 pt`.
- Базовый интерлиньяж — `1.2`.
- Если веб-файлы Normalidad не будут переданы, используется предусмотренный
  гайдом fallback Verdana.

## Компоновка

- Базовая сетка — `10 × 10`.
- Тексты и логотип выравниваются по левому краю.
- На одном экране используется не более одного фирменного «Переключателя».
- На мобильном экране должен оставаться один главный фокус.

## Иллюстрации

- Плоская геометричная шейповая графика с небольшим количеством линий.
- Простые прямые ракурсы, скруглённые углы и единая толщина линий.
- Основной цвет линии — `#6B3F26`.
- Допустимы лёгкие шумовые текстуры, если они не перекрывают контент.
- Не используются изометрия, локальные 3D-объекты и чёрные тени.
- Транспорт, карта и окружение должны выглядеть частью одной иллюстрационной
  системы.
