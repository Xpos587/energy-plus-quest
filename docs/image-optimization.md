# Изображения и загрузка основной игры

Исходники остаются в `public/scene-art/`, `public/compact-art/`, `public/scene1-live/`, `public/review/carrier-art-2026-09-27/` и импортированных карточках `design/scene-01/assets/current/choices/`. Меняйте исходный рисунок, затем запускайте обычную сборку или публикацию. Ручная конвертация и обновление ссылок не нужны.

Production-плагин `scripts/optimized-images.ts` создаёт отдельные файлы с именами от содержимого в `dist/assets/`. Актуальные панорамы, результаты и постер карты получают AVIF и WebP: полный размер и варианты шириной 1280/1600 px, когда они меньше исходника. Нативный `picture` выбирает формат и разрешение с учётом экрана и плотности пикселей. WebP и обычный `img` сохраняют совместимый путь для старых встроенных браузеров. Пропорции и прозрачность сохраняются; оригиналы не перезаписываются. Карточки подготовки ограничены шириной 768 px. Настройки: AVIF quality 60 / effort 4, WebP полного размера 88, уменьшенного 80, альфа 100. Уже более компактный исходный WebP сохраняется.

Замена рисунка под тем же исходным именем меняет опубликованный URL и обходит старый кэш. Для новых публичных путей используйте `imageAsset()` и `ImageSources`; актуальные фоны определяются `src/scenes/worldManifest.json`, результаты — `src/scenes/artwork.ts` и таблицей обрамления крана. Компактные результаты определяются `src/scenes/compact/artwork.ts`. Исторические картинки не получают дополнительные AVIF-версии без необходимости. Кодек хранит локальный кэш в `.tmp-work/image-build-cache`, сравнивает исходные байты и перекодирует изменённое. Удаление кэша безопасно, но следующая сборка займёт дольше.

Аватары выбранного профиля, получателя и подарка в шапке используют отдельные WebP шириной 128 px через `thumbnailAsset()`. Крупные карточки подготовки остаются 768 px: уменьшение служит только миниатюрам. Обе версии пересобираются при замене исходника.

В разработке используются оригиналы, новые изображения видны сразу. Облегчение проверяется production-сборкой. Вложенный путь и сборка с инлайн JS/CSS поддерживаются; изображения остаются отдельными файлами.

Очередь заранее загружает следующий фон и выбранный результат после текущих изображений, по одному запросу с низким приоритетом. На 2G и при экономии трафика прогрев отключён. Он использует тот же выбор формата и размеров, что показ сцены. Результат перевозчика содержит один `img`: телефон не скачивает одновременно мобильный и настольный рисунок. Если рисунок не загрузился, игрок видит сообщение и кнопку повтора; повторный запрос получает новый параметр URL.

Видео карты необязательно: сначала доступен статичный постер с выбором грузовиков. Видео начинается после иллюстраций; экономия трафика, слабая сеть, наблюдаемая медленная передача, ошибка видео и настройка уменьшенного движения оставляют статичный вариант. Проверка фактической скорости дополняет Network Information, поскольку эта подсказка доступна не во всех браузерах.

Плагин `scripts/optimized-fonts.ts` сокращает три WOFF2 без изменения исходников: сохраняет латиницу, кириллицу, знаки интерфейса и символы актуальных исходников, JSON и Unicode-escape. При следующих правках текста набор пересобирается. Требуется `uv`; версии fonttools/brotli закреплены в `scripts/subset-fonts.py`. Лицензионные сведения шрифта сохраняются.

На HTTPS (и localhost) необязательный `quest-cache.js` сохраняет оболочку и уже запрошенные ресурсы игры. Первое посещение сохраняется даже до получения контроля над страницей. Успешный повтор после ошибки сохраняется под обычным адресом изображения, чтобы оно было доступно после перезагрузки без сети; остальные параметры URL сохраняются. Лимит — 80 записей на выпуск и два выпуска, видео не сохраняется. HTML проверяется через сеть, при обрыве доступна сохранённая оболочка. Новая версия ждёт закрытия старых вкладок; замена файлов с новым URL не выдаёт старую картинку. Отсутствие или блокировка service worker не мешает обычной игре. Хранилище может быть очищено браузером: непосещённые сцены и ресурсы без сохранённой копии требуют соединения.

Сервер сжимает текстовые файлы gzip. HTML и `quest-cache.js` перепроверяются, файлы с именами от содержимого кэшируются на год, обычные изменяемые изображения — на сутки. Заголовки другого сервера настраиваются отдельно.

Проверки:

```sh
bun test scripts/optimized-images.test.ts scripts/optimized-fonts.test.ts scripts/game-cache.test.ts
bun run test src/game/imageLoading.test.tsx src/game/imageQueue.test.ts src/game/network.test.ts src/game/offlineCache.test.ts src/components/mapLoading.test.tsx src/components/useArtworkLoading.test.tsx
bun run build
bunx vite preview --host 127.0.0.1 --port 4318
bun scripts/verify-image-optimization.mjs http://127.0.0.1:4318/
```

Последняя команда проверяет 31 результат и повтор после ошибки. Второй аргумент — адрес сохранённой исходной сборки для сравнения.
