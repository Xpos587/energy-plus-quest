# Отдельный вариант общего интерфейса

Страница просмотра: `/design/shared-interface-v2/index.html` на сервере Vite проекта. Входная точка игры и рабочие компоненты не изменены. Эта страница импортирует компоненты иллюстраций и данные сценария для проверки настоящих условий; её стили загружаются только здесь, а состояния выбора живут в памяти страницы. Сохранения игры не читаются и не записываются.

Проверяем сочетание текущих сцен с лёгкими карточками, короткими подписями отметок и термином «Ситуация». На телефоне используются реальные контейнеры горизонтальной прокрутки. Вопрос остаётся над сценой, описание появляется снизу. При просмотре варианта прочие отметки сокращаются до номера, выбранная сохраняет подпись. Переключение пяти сцен и подарка находится в «Маршруте».

Цвета и логотипы взяты из [канонического брендового контракта](../../DESIGN.md). Шрифт — текущий локальный Roboto Condensed из проекта, используемый как замена недоступной коммерческой Normalidad; это не копия фирменного шрифта. [Описание шрифтов](../../public/fonts/README.md).

Тексты условий, вариантов и последствий берутся из модулей игры. Короткие подписи отметок принадлежат только этому варианту. Экран результата здесь проверяет чтение настоящего текста; полный игровой экран результата, показатели и итоговое сохранение не заменены этим прототипом.

Проверка: `bunx playwright test --config=design/shared-interface-v2/playwright.config.ts` при работающем сервере на `http://127.0.0.1:4184`. Тесты проверяют раздельные просмотр и подтверждение, отмену и настоящий жест прокрутки во всех пяти сценах на 320×568 и 390×844.
