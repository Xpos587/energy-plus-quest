Основа: `public/compact-art/loading-organized-v5.png`.
Результат: `public/compact-art/loading-niche-v6.png`.
Метод: built-in imagegen, редактирование отдельного фрагмента, затем масочная композиция.
Область исходника: x=1075, y=600, ширина=640, высота=480. Остальные RGB-пиксели совпадают с исходником (максимальная разница вне области: 0).

Без подарка и интерфейсной разметки.
