# Погрузка на баржу: набор кадров v2

## Единый визуальный контракт

Все пять кадров редактировались встроенным ImageGen на основе одного базового изображения. Сохранять широкий изометрический ракурс, тонкие серые контуры, спокойные заливки и мягкие тени. Склад расположен слева сверху, ПРУ — слева у ближнего крана, дальний кран и Пётр — справа сверху, баржа с трубами — справа снизу у диагонального причала. Люди, груз, тележка, краны и баржа должны быть соразмерны. У деревьев лишь начало осени: немного жёлтых крон среди зелёных. На ПРУ — читаемая надпись «ПРУ»; повреждённые псевдонадписи на складе и над дверью ПРУ удалены. Трубы — прямые параллельные связки одинакового диаметра, закреплённые внутри трюма. В кадрах нет дополнительных кранов, барж и копий подарка.

## Промпты состояний

| Кадр | Изменение относительно базового изображения |
| --- | --- |
| [До выбора](../../../public/scene-art/crane-v2.png) | Очистить повреждённые надписи, сохранить «ПРУ», обновить связки труб, добавить сдержанную раннюю осень. Подарок стоит на тележке у причала. |
| [Позвать Ивана](../../../public/scene-art/outcomes/crane-rush-v2.png) | Иван после работы стоит у ближнего крана, немного устал; тележка пуста, один подарок лежит на свободной палубе баржи рядом с трубами; баржа начинает отходить. |
| [Ждать кран](../../../public/scene-art/outcomes/crane-wait-v2.png) | Кран не работал; баржа с трубами отходит без подарка, подарок остаётся на тележке, Иван у ПРУ смотрит на время. |
| [Позвать Петра](../../../public/scene-art/outcomes/crane-petr-v2.png) | Пётр находится у ближнего крана после погрузки подарка. Один подарок на барже, тележка пуста. Его отдельные ящики ожидают у дальнего крана на сухом причале. |
| [Управлять удалённо](../../../public/scene-art/outcomes/crane-remote-v2.png) | Иван сидит за пультом внутри ПРУ и виден через окно. Один подарок уже на барже, тележка пуста, кран работает дистанционно. |

Проверять каждый результат рядом с базовым кадром на [странице сравнения](../../../public/review/barge-v2.html), затем в самой игре на узком телефоне и на компьютере.
