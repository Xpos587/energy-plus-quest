# Баржа: крупные результаты

> Исторический рабочий материал: его формулировки и решения не являются актуальным сценарием. Единственный сценарный источник — [редакция 08.10](../../../docs/scenario.md).


## Текущее решение после ревью

Пользователь принял общее направление компьютерных кадров Ивана, ожидания и ПРУ. Отдельно сгенерированные мобильные иллюстрации полностью отклонены. На телефоне показывается неподвижная обрезка того же компьютерного файла; ракурс выбирается отдельно для каждого результата.

Кадр Петра — `crane-petr-v7-desktop.png`. В v6 пользователь оценил улучшение персонажей, но отклонил анимешные лица. В v7 через ImageGen изменены лица обоих работников: небольшие тёмные глаза без бликов, спокойные брови, упрощённые взрослые черты по персонажам приложенного референса. Сохранены сине-оранжевые рабочие костюмы, российские шевроны, позы и непрерывный причал. Правила бренда: [персонажи и одежда](../../../DESIGN.md#лица-и-персонажи). Пользователь одобрил лица v7 и затем применение остальных обновлённых кадров. Все четыре результата подключены к игровой сцене.

## Канонические источники

После одобрения лиц в кадре Петра v7 тот же образ Ивана перенесён через ImageGen в `crane-rush-v4-desktop.png`, `crane-wait-v4-desktop.png` и `crane-remote-v4-desktop.png`: небольшие глаза без бликов, упрощённые взрослые черты, одинаковая сине-оранжевая спецодежда. Сохранены действия каждого результата. Все три новых кадра проверены в игре при 320×568, 390×844 и 1440×900; мобильные снимки обновлены.

- Файлы кадров и горизонтальные позиции мобильной обрезки: [outcomeFraming.json](../../../src/scenes/crane/outcomeFraming.json).
- География и стилистика: `public/scene-art/crane-v2.png`.
- Сюжет: `src/scenes/implementationText.ts`, id p448, p461, p467–p471, p479–p489.
- Страница сравнения: `/review/barge-v2.html` (сохранён адрес открытой страницы).
- Примеры на телефоне: `public/review/barge-crops/`, снимки настоящего экрана результата 320×568.

## Смысл обрезок

Иван — работник после погрузки рядом с ближним краном. Ожидание — часы Ивана и подарок на тележке. Пётр — расстроенный Пётр и благодарный Иван. ПРУ — Иван за пультом удалённого управления. В мобильном кадре может оставаться лишь часть баржи и инфраструктуры за пределами главного действия.

Все четыре состояния просмотрены при 320×568, 390×844 и 1440×900. На всех размерах загружается тот же компьютерный файл. Горизонтальная прокрутка результата отсутствует; полный текст открывается по нажатию. Предыдущие мобильные файлы сохранены только как история и не подключены к игре или сравнению.
