# Главная сцена погрузки на баржу · V1 · 10.10.2026

Применено в основной локальной игре `/`: одинаковые квадратные номера в сцене и карточках; MobileSAM-контуры ближайшего крана (общий для 1 и 2), крана Петра (3) и ПРУ (4). Текстовые плашки с изображения убраны. Подсветка статичная. Пешеходный путь до лестницы показывается только для действия rush (выбор/наведение/клавиатурный фокус), остальные способы не подразумевают этот переход. Нажатие на общий силуэт крана фокусирует номер, не выбирает способ автоматически.

Условия до выбора берутся из канона: судно готово, кран освободится через три часа, Иван ждёт распоряжений, у Петра начинается своя погрузка. Формулировка про Петра выведена с его именем и дословной второй частью варианта. Короткие кнопки раскрывают полную формулировку сценария перед подтверждением. Исходы и баллы заранее не показываются.

Канон: [сценарий](../../docs/scenario.md), блоки 62451EC9, 6F7BE91B, 0C6EC2FC и четыре варианта сцены 4. Сценарное противоречие между «кран освободится через три часа» и немедленными альтернативами не исправлено выдуманным объяснением; требует решения автора сценария.

## Проверка

- `capture.mjs`: основная игра на 320×568, 393×852, 820×1180, 1440×900; ошибок runtime и горизонтального переполнения нет.
- `verify.mjs`: все четыре маркера на каждом размере открывают правильный полный текст, карточки видны, hit targets минимум44×44; отмена возвращает к выбору, подтверждение remote открывает результат; путь показывается только для rush.
- 28 профильных unit-тестов проходят; TypeScript проходит.
- Независимые read-only оценки игрока, геймдизайна и документированных замечаний Феди. Это не согласование Феди. Замечание о ложном обязательном маршруте исправлено. На320px общий кадр мелкий; детали проверяются при инспекции/приближении.
