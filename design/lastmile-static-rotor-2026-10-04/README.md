# Статичный винт · 04.10.2026

По запросу Michael удалён отдельный SVG-слой HelicopterRotors вместе с CSS-анимациями. В четыре текущих choice-изображения встроен неподвижный винт. Цвет вертолёта сохранён оранжевым; задан уточняющий вопрос о возможной перекраске, ответа на момент применения не было.

Imagegen исправил винт; apply.mjs переносит только локальную область вертолёта из результата в исходную сцену. Оригиналы сохранены в before/. Пути runtime сохранены, чтобы все существующие способы показа сцены использовали исправление. Код первой сцены не затронут.
