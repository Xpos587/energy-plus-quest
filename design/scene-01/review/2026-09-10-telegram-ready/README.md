# Скриншоты игры для согласования

Свежие снимки локальной версии. Ничего не отправлено и не опубликовано.

- `desktop/`: основные пять экранов, PNG 3840x2160.
- `mobile/`: те же экраны, PNG 1170x2532.
- `extras/` внутри каждой папки: остальные четыре результата выбора перевозчика.
- `contact-sheet.jpg`: обзор всех 18 снимков.
- `manifest.json`: размеры, контрольные суммы и сведения о снимках.

Порядок основных экранов: профиль, получатель, подарок, карта, результат с двумя водителями. Один путь: профессионал → Арсений → фотоаппарат. На карте номера привязаны к машинам, соединительных линий нет.

В шапке «Энергия+» находится слева, логотип ГПН-С — справа. Синий логотип увеличен относительно оранжевого для визуального равновесия; исходные официальные SVG не изменены.

В дополнительных снимках: №1, №4, №2 и автоматический подбор Express. Отдельные сцены склада, баржи и последней мили не включены: они пока не реализованы в игре.

`scene-01-telegram-ready.zip` — готовый архив с этим набором. Отправка только после отдельного разрешения.
