# Согласованная шапка — свежие скриншоты игры

Все снимки заново сделаны после согласования шапки r41. Логотипы, код, иллюстрации и движение машин не изменялись при подготовке пакета. Ничего не отправлено и не опубликовано.

- `desktop/`: пять основных экранов, PNG 3840x2160.
- `mobile/`: пять основных экранов, PNG 1170x2532.
- `extras/` в каждой папке: четыре остальных результата выбора перевозчика.
- `contact-sheet.jpg`: обзор всех 18 снимков.
- `manifest.json`: размеры, контрольные суммы и параметры фактически отображённой шапки.

Основной путь: профессионал → Арсений → фотоаппарат → карта → результат с двумя водителями. Дополнительно: результаты №1, №4, №2 и Express. Будущие, ещё не реализованные сцены не добавлялись.

PNG оптимизированы без изменения цветов и пикселей. Архив `scene-01-telegram-approved.zip` содержит только этот свежий набор, без вложенных старых архивов.

Отправка в Telegram — только после отдельного разрешения.
