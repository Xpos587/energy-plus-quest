# Передача в реализацию

Прочитать [направление](DESIGN.md), [решение по референсам](design-contract.md),
[актуальные требования](../../../docs/requirements.md),
[бренд-гайд](../../../DESIGN.md) и [визуальный контракт первой сцены](../../../docs/scenarios/01-visual-contract.md).

1. Сначала проверить один полный цикл: цель → действие внутри сцены → видимое
   следствие → короткое объяснение → продолжение маршрута.
2. Использовать брендовые цвета, шрифты, сетку и логотипы по корневому
   `DESIGN.md`; новые фактуры применять внутри оригинальных иллюстраций.
3. Сохранить текущий сценарий, четыре варианта перевозчика и баллы. Не
   добавлять новые механики ради сходства с референсом.
4. Проектировать mobile отдельно: видимые ключевые объекты, читаемая цель,
   доступные пальцем действия, отсутствие перекрытий.
5. Первый артефакт должен доказать, что игрок понимает задачу по картине,
   делает выбор в сцене и сразу видит, что изменилось.
