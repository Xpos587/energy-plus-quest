# Финал игры — визуальная проверка

Тексты и условия профилей: [канонический сценарий](../../docs/scenario.md#ending).

- Семь сертификатов: четыре для студента и три для профессионала.
- Реальные экраны: 1440×900, 820×1180, 390×844 и 320×568.
- Все профили достижимы через существующие варианты игры; маршруты проверяет `certificateBranches.test.ts`.
- Экспорт: PNG 1200×1400, без приглашения в компанию; для публикации «ваших» заменяется на «моих».
- На поддерживаемых устройствах доступна системная отправка файла. Для VK/Telegram предусмотрены ссылки с текстом и сохранение изображения для ручного прикрепления.
- «Пройти заново» открывает выбор персонажа. «Вернуться на главную» открывает обложку. Обновление страницы сохраняет открытый сертификат.
- Адрес для приглашения в компанию/на практику не согласован. Приглашение оставлено текстом, без выдуманного URL.

`verification.json` содержит результаты браузерной проверки. Системная отправка проверяется подменой API без отправки внешних сообщений.

Иллюстрации развязки повышенного разрешения находятся в `public/scene-art/resolution-v2/`. Для всех трёх получателей фотоподарок сохраняет белую рамку открытки. Экраны развязки и отдельный отчёт проверки находятся в `resolution/`.
