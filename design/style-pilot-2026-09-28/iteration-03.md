# Рабочая запись V3 — не включать во внешний PDF

Запрос пользователя: в PDF обязательно сравнивать с исходной сценой из игры, а не только с предыдущими генерациями. Новый независимый критик — GPT-6 Astra medium, fork_turns=none. Переданы только изображения и реальные прошлые слова Феди; история итераций, промпты и наши объяснения не передавались. Роль — требовательный арт-директор по критериям Феди, без приписывания ему одобрения.

Критика: мобильная панель скрывает груз; у работника больше сосредоточенности, чем усталости; сложенная лодка может напоминать сумку; фон слишком насыщенный и блестящий. Первое и четвёртое подтверждены сравнением, второе принято как пробная адресная правка. Предложение раскрыть кокпит не принято: оно меняет состояние сложенного груза. Узнаваемость упаковки остаётся вопросом предметного согласования.

Исходники из production сохранены в baseline/warehouse.webp и baseline/outcome.webp. Внешний пакет 02 показывает их как «До · исходная сцена» и новые изображения как «После». Номера иллюстраций сохраняются: склад V2, последствие V3; номер PDF-пакета отдельный.

Пробная адаптация интерфейса реализована только в capture-v3.mjs: реальный DOM приложения и сценарный текст, новые изображения и CSS подставляются в браузере. Это макет для ревью, не production-изменение. Область иллюстрации расположена между шапкой и результатом, без перекрытия панелями. Полный текст остаётся доступным в существующем скроллере. Для высокого телефона — квадратная композиция того же события; для 320×568 — широкий кадр. Не называть эти скриншоты внедрённым интерфейсом.

Проверка: desktop 1440×900, phone 390×844, small 320×568; исходный/новый кадр, равенство текста, доступность конца текста скроллом, возврат к выбору через брифинг. Результаты — capture-v3-receipt.json. Повторные замечания — final-review-03.md.

Следующий этап после выбора визуального направления: внедрять согласованный вариант подачи в общий интерфейс отдельно с проверкой остальных результатов; затем переносить правила на семейство склада и анимационные кадры. Не распространять экспериментальный CSS на все сцены автоматически.
