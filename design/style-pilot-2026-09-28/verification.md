# Проверка пилота

28 сентября 2026. Выполнены четыре генерации/редактирования встроенным imagegen, три независимые роли GPT-6 Astra с чистым начальным контекстом и повторные проверки исправлений. Это не согласование Феди.

## Решения по критике

| Область | Наблюдение | Решение и итог |
|---|---|---|
| География склада | Приёмка слева, отгрузка справа, три пары стеллажей и порядок букв сохранены | Правки географии не нужны; визуальная проверка, не точное сравнение пикселей |
| Стойки/ворота, x=.23–.81 y=.09–.77 | Излишняя насыщенность и узкие блики | Принято после сравнения. V2 спокойнее; оранжевые ограждения ещё блестят |
| Коробки, x=.24–.42 y=.10–.57 | Плотная внутренняя линия | Частично принято: ослаблена, конструктивная линия сохранена |
| Работник и тележка V1, x=.15–.58 y=.27–.94 | Движение от ворот вместо к воротам | Подтверждено ведущим. V2 меняет только группу и материал; критик подтвердил направление |
| Лицо и поза V2 | Нет улыбки, есть наклон/усилие; измотанность менее выражена, чем V1 | Остаточная гипотеза для художественного сравнения. Не притворяемся, что согласовано |
| Лодка | Синие баллоны, оранжевые ручки/весло узнаваемы | Предметная идентичность улучшена; способ упаковки остаётся предложением |

## Проверка в приложении

`bun design/style-pilot-2026-09-28/capture.mjs` — шесть кадров: общий склад и результат для 1440×900, 390×844, 320×568. `capture-receipt.json` фиксирует подменённые URL и загрузку картинок. В каждом размере обе подмены сработали, изображения загрузились, переполнения документа по горизонтали нет. Это не означает художественную приёмку.

Просмотр кадров ведущим обнаружил **блокер внедрения**: мобильная панель результата закрывает груз; 320×568 почти полностью скрывает действие. На desktop читаются лицо и лодка, нижняя часть тележки под панелью. Поэтому V2 не следует ставить в production как готовую замену.

Следующая ограниченная работа: согласовать отдельную мобильную композицию/область показа с владельцем общего интерфейса, обеспечить одновременно видимые лицо, лодку и направление движения, затем повторить те же три кадра. Тексты и баллы не сокращать ради картинки. В рамках художественного пилота общий интерфейс не переписывался.

## Что не доказано

- Полная тождественность геометрии склада между разными камерами: есть визуальная связность, но нет общей 3D-модели как строгого источника.
- Пиксельная локальность редактирования: запрос ограничивает область, но модель может перерисовывать другие пиксели. Для строгой локальности понадобится маска/композитинг с отдельной проверкой границы.
- Детерминизм backend, seed и checkpoint не раскрываются этим инструментом.
- Анимация и единообразие остальных сцен не проверены этим пилотом.

Для следующего агента: сначала README.md → prompts.json → этот файл → изображения. Не начинать новый аудит с нуля. Нельзя трактовать pass критика как одобрение Феди.
