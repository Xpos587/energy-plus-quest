## Обязательные входы каждого запроса

1. [Неизменный стилевой эталон](../../style-audit-2026-09-28/reference.png).
2. Композиция конкретной сцены и общий склад.
3. Тот же предмет: лодка с мотором из алфавитного исхода.
4. Реальные изображения персонажей: [Профессионал](../../scene-01/assets/current/choices/professional.webp), [Арсений](../../scene-01/assets/current/choices/arseniy.webp). Лица нельзя задавать только словами и позволять модели изобретать замену. Сравнивать нос, глаза, щёки, подбородок, возраст и причёску крупно. Указание внешности не заменяет визуального эталона.
5. [Контракт спецодежды](../uniform-contract.md), включая различие переда/спины и анатомическую сторону шевронов.

Первые версии новых лиц отвергнуты пользователем. Keeper V1–V3 и WMS V1–V4 — промежуточные, не выбирать автоматически по названию. Последние локальные правки переносили лица по эталонам, устраняли улыбки в неудачном исходе и проверяли одежду после каждого изменения. Сходство не означает согласование пользователем или Федей. Мелкая точность корпоративных знаков не сертифицирована.

## Сюжетные инварианты

Источник: [inventory/index.ts](../../../src/scenes/inventory/index.ts) и [Текущие тексты реализации](../../../src/scenes/implementationText.ts), p355–p379.

- Приёмка: подарок далеко от отгрузки, лишний путь.
- Алфавит: лодка в середине, сотрудники устали собирать общую поставку.
- Кладовщик: место близко к отгрузке, но новая смена его не знает и ищет груз. Не изображать кладовщика успешно передающим знания.
- WMS: правильный груз быстро находят у отгрузки; сканер направлен на реальную бирку этого груза.

## Воспроизведение

Промпты: [первые версии](prompts.json), [коррекция персонажей](character-corrections.json), [локальные уточнения](refinement-prompts.json), [полоса WMS](wms-sleeve-prompt.json). Встроенный инструмент не раскрывает seed/версию модели: детерминированность не обещается.

Снимки через [capture-family-current.mjs](../capture-family-current.mjs), параметры PILOT_BRANCH и PILOT_ART. Подмена изображений и CSS только внутри браузера для макета. Три размера: 1440×900, 390×844, 320×568. Полные постраничные тексты сравниваются до/после. Широкие кадры показаны целиком, без обрезки лиц или груза; новые квадратные варианты ещё не изготовлены. Для алфавита сохранена ранее подготовленная квадратная адаптация.

PDF: `bun design/style-pilot-2026-09-28/export-family-04.mjs`. Внешний PDF содержит только изображения, метаданные и статус; внутренние замечания остаются здесь.
