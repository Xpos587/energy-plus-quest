## Как повторять

Встроенный imagegen; точные запросы в prompts.json. В каждый запрос входит неизменный стиль-референс, отдельно композиция/предметы. Сохраняем все версии. Критика: область → наблюдение → гипотеза → решение ведущего → ограниченная правка → повторная проверка.

Использованный инструмент не раскрывает checkpoint и seed. Детерминизм не подтверждён: сохранён воспроизводимый порядок работы и входы, но идентичные пиксели при повторе не обещаем. Финальный производственный рецепт модели ещё не выбран. Higgsfield проверен как доступный дополнительный инструмент; эти картинки сделаны встроенным imagegen.

## Граница пилота

Одна семья из двух статичных экранов. Тексты, баллы и механики не меняются. Проверка в игре выполняется подменой запросов только в Playwright, без изменения production assets. Для анимации сначала фиксируем принятые постеры/географию; затем проверяем движение и первый/последний кадры по ним. Анимация этим проходом не изготовлена и не принята.
