# Склад: единые результаты V1 · 03.10.2026

По прямому разрешению Michael: удачные кадры унифицированы, лодка и мотор заменены закрытыми нейтральными коробками. Четыре мастера для всех трёх подарков и размеров экрана. Другой ракурс под телефон больше не подставляется. Основная сцена склада этим проходом не менялась.

- alphabet-v1: исходный inventory-alphabet-boat-panorama-v1; сохранён принятый жест у лба. Ближайшая конкретная буква заменена нейтральной маркировкой, дальняя А-Б остаётся. Переменная буква/позиция из сценария остаётся в тексте.
- wms-v1: исходный inventory-wms-boat-family-v1; сохранены лицо, сканер, компьютер WMS, ладонь на коробке.
- keeper-v1: исходный inventory-keeper-boat-family-v1; сохранён поиск новой сменой. На стеллаже закрытые коробки вместо лодки.
- entrance-v1: исходный inventory-entrance-boat-panorama-v1; исправный ракурс тележки, коробки вместо лодки, лёгкая усталость без злости. Окончательная субъективная оценка эмоции остаётся за Michael.

Генерация: встроенный imagegen, по одному редактированию на кадр. Общее требование промптов: localized image edit, neutral sealed kraft cartons instead of visible boat and motor; preserve original adult faces, poses, uniform, cart, warehouse layout and clean illustrated style; no gift imagery, contents, blur, sepia or mottling. Для alphabet убрать ближайшую Л-М; для WMS сохранить касание коробки и сканирование штрихкода; для keeper не менять жесты поиска; для entrance слегка опустить плечи, обе руки на ручке, небольшой наклон и выдох без грусти/злости. Нативные PNG лежат рядом. Runtime WebP: public/scene-art/warehouse-neutral-2026-10-03.

Маршрутизация: src/scenes/artwork.ts; inventory panorama override удалён из src/scenes/SceneOutcomeArt.tsx. Тексты сценария, баллы и варианты не менялись. Старые файлы не удалены, но не выбираются для складских результатов.
