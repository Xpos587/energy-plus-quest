# Energy+ Quest

Браузерная игра-квест «Доставляем радость» для площадки «Энергия+».

## Что делаем сейчас

1. Согласовываем с Эдиком оценку `180 000 ₽` за пять сцен и три итерации на
   каждую.
2. Передаём технарям два вопроса: подходит ли статический HTML/CSS/JS-архив без
   backend и есть ли требования к стеку или формату архива.
3. Делаем первую играбельную версию сцены Express за `7–10 рабочих дней` после
   согласования старта.
