# Energy+ Quest

Рабочий репозиторий браузерной игры-квеста «Доставляем радость» для проекта
«Энергия+».

Проект находится на этапе проверки сценария и технических ограничений площадки.
Рабочий стек — React, TypeScript и Vite со статической сборкой; точный способ
интеграции в «Энергию+» будет зафиксирован после ответа технической команды.
