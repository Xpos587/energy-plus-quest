# Energy+ Quest

Браузерная игра-квест «Доставляем радость» для площадки «Энергия+».

## Что делаем сейчас

Первая играбельная версия сцены Express готова к показу Феде:

- онбординг с выбором профиля, получателя и посылки;
- интерактивная карта с четырьмя вариантами перевозки;
- последствия решений и три показателя игрока;
- обязательное сравнение ручного выбора с Express;
- mobile и desktop;
- статическая production-сборка без backend.

Техническая команда площадки подтвердила формат автономного статического
HTML/CSS/JS-архива. Первый архив они разместят на тестовом окружении как
отдельный спецпроект; backend и интеграция с WordPress сейчас не нужны.

## Запуск

```bash
bun install
bun run dev
```

Полная локальная проверка:

```bash
go-task verify
bun run test:e2e
```

Сборка проверенного архива для тестового окружения заказчика:

```bash
go-task release
```

Результат: `release/energy-plus-quest-static.zip`. `index.html` находится в
корне архива, а относительные пути проверяются из вложенной папки спецпроекта.

Целевой URL площадки: `https://e-plus.media/specprojects/joydelivery/`.
