# Energy+ Quest

Рабочий репозиторий браузерной игры-квеста «Доставляем радость» для проекта
«Энергия+».

Проект находится на этапе проверки сценария и технических ограничений площадки.
Технологический стек будет выбран после ответов команды заказчика по интеграции.

## Документы

- [Требования](docs/requirements.md) — единый источник продуктовых требований.
- [Источники](docs/sources.md) — каталог полученных материалов и их статусов.
- [Разбор DOCX](docs/docx-analysis.md) — выводы из паспорта и драфта первой
  сцены, включая найденные противоречия.
- [Бренд-ограничения](docs/brand-constraints.md) — правила фирменного стиля для
  веб-квеста.
- [Первая сцена](docs/scenarios/01-express.md) — нормализованный сценарий и
  первичная проверка.
- [Вопросы заказчику](docs/questions-for-client.md) — технические вопросы для Феди.
- [Коммерческий контекст](docs/commercial-context.md) — история оценки и текущий
  состав оплачиваемой работы.

## Исходные материалы

Полученные документы, бренд-гайды, аудио встречи и транскрипции хранятся в
[`materials/`](materials/). Репозиторий приватный. Исходное видео встречи не
добавлено из-за размера; вместо него сохранены аудиодорожка и полный транскрипт.
