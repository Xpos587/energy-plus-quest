# Energy+ Quest

Рабочий репозиторий браузерной игры-квеста для карьерного проекта «Энергия+».

Проект находится на этапе сбора и проверки исходных материалов. Технологический
стек и финальный объём работ будут выбраны после изучения документов заказчика.

## Документы

- [Требования](docs/requirements.md) — текущий контекст, границы и открытые вопросы.

## Конфиденциальные материалы

Исходные записи встреч и непубличные клиентские файлы не добавляются в Git.
Локально их можно хранить в `materials/private/`.
