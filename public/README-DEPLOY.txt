Энергия+ — «Доставляем радость»
Автономный статичный preview первой сцены

КАК РАЗМЕСТИТЬ

1. Распакуйте содержимое архива в отдельную папку спецпроекта.
2. Файл index.html должен находиться непосредственно в корне этой папки.
3. Открывайте спецпроект отдельной ссылкой в новой вкладке.

Целевой production-URL:
https://e-plus.media/specprojects/joydelivery/

ЛОКАЛЬНАЯ ПРОВЕРКА

- Не открывайте index.html двойным кликом через адрес `file://`: современные
  браузеры блокируют загрузку ES-модулей и CSS из локального файла.
- После распаковки из каталога архива запустите любой статический HTTP-сервер,
  например: `busybox httpd -f -p 4174 -h .`
- Затем откройте `http://127.0.0.1:4174/`.

После распаковки структура начинается так:

index.html
assets/
brand/
fonts/

ТЕХНИЧЕСКИЕ УСЛОВИЯ

- Нужна только раздача статических файлов по HTTPS.
- PHP, WordPress-плагины, Node.js, база данных и API не требуются.
- Все ресурсы находятся внутри архива; внешние CDN не используются.
- Не следует оборачивать index.html в шаблон WordPress или внедрять в него
  глобальные стили сайта.
- Сервер должен отдавать корректные MIME-типы для JS, CSS, WebP, PNG и WOFF2.

ПУБЛИКАЦИЯ В PRODUCTION

- Распакуйте архив в webroot/specprojects/joydelivery/.
- Пример location-блоков Nginx находится в deploy/nginx-joydelivery.conf в
  репозитории проекта.
- index.html отдаётся без кеша; ассеты с хешами можно кешировать на год.

РЕКОМЕНДУЕМОЕ КЕШИРОВАНИЕ

- index.html: no-cache или короткий TTL;
- assets/*: public, max-age=31536000, immutable;
- fonts/* и brand/*: длительный кеш с перевалидацией.

ЧТО ПРОВЕРИТЬ ПОСЛЕ РАЗМЕЩЕНИЯ

1. Игра открывается в новой вкладке без ошибок загрузки.
2. Доступны выбор профиля, получателя, подарка и пять вариантов перевозчика.
   Каждый вариант открывает результат; «Назад к машинам» сохраняет выбранный контекст.
   На результате доступен возврат к карте; продолжение обозначено как недоступное, без неработающей кнопки.
3. Нет горизонтальной или вертикальной прокрутки игрового экрана.
4. Проверены мобильный экран, планшет, desktop и Windows/browser zoom 125%/140%.

СТАТУС

Это preview для проверки визуального направления, а не согласованная готовая
игра. Публикация требует отдельного разрешения. Карта статична: проверенный
motion-прототип не прошёл критерии бесшовного цикла и не включён в runtime.
Официальные маркировки СИЗ и визуальное согласование остаются pending.
Сцены 2–5 не включены: их подробные сценарии заказчик готовит отдельно. Хранение результатов, аккаунты, email, аналитика через API и
интеграция с WordPress сейчас не требуются и в архив не входят.
