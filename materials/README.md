# Материалы проекта

В этой папке лежат полученные исходники, необходимые для повторной проверки
требований. Файлы не редактируются; рабочие выводы находятся в `docs/`.

## Состав

- `meeting/2026-07-30-zoom-transcript.txt` — основной источник актуальных
  договорённостей;
- `meeting/2026-07-30-zoom-audio.mp3` — аудиодорожка той же встречи;
- `meeting/repository-setup-request.ogg` — голосовая постановка задачи по
  инициализации проекта;
- `project/` — согласованный паспорт и драфт первой сцены из Telegram;
- `brand/` — четыре предоставленных PDF-гайда «Энергии+»;
- `telegram/chat-context.md` — проверенный контекст переписки с Эдиком без
  персонального e-mail и действующего параметра доступа к Zoom.

Исходное видео встречи не добавлено: оно занимает около 2,3 ГБ и не подходит
для обычного GitHub-репозитория. Для работы сохранены аудио и транскрипция.
